# 审批内部开发规范

继承 [项目规范](../../../AGENTS.md) 与 [恢复规范](../AGENTS.md)。审核、许可及恢复接口约定见 [README](README.md)，覆盖归属见 [集中测试](../../../tests/README.md)。

- 公开接口约定由父层重导出；存储、事件与许可构造字段保持父域私有，内部模块仅开放父域所需接口。
- 请求/审核与许可/结果入口均经过父域当前政策核验和统一持久变更入口，人工决定不得绕过硬政策。
- 迁移保持纯计算；实时操作与回放使用同一校验，存储同步成功后才安装内存或交付许可。
- 保持完整操作绑定、审核尝试/记录版本号/截止时间绑定、人工拒绝终态、一次消费和 Unknown 执行结果核实语义，不从模型响应构造审核身份或执行许可。
- 不弱化路径与文件对象身份、单写锁、容量拒绝、损坏拒绝和写失败停用规则；只读查询结果不能替代变更前核验。

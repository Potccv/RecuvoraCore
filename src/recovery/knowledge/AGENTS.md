# 知识库开发规范

继承[项目规范](../../../AGENTS.md)与[恢复规范](../AGENTS.md)。公开接口见[README](README.md)，测试归属见[集中测试](../../../tests/README.md)。

- 本域只进行确定性状态计算和查询；不得引入文件、存储客户端、外部异步调用、时钟读取或知识源生命周期。
- 候选和案例全局幂等、不可变脚本版本、可信验收绑定及永久隔离必须在实时提案与历史恢复中使用相同校验。
- 所有权威变更先返回提交提案；Host 可靠原子提交并确认后才能安装状态，不将发送成功视为提交成功。
- 模型和外部知识仅提供候选；可信验收与提交确认不得增加直接反序列化入口，历史恢复也不能跳过领域校验。
- 精确适用性、隔离和复用过滤先于限额，可信排序保持稳定；外部批次必须固定来源、有界字段及字节、整体拒绝内容冲突。
- 不删除旧案例、不可变版本、幂等键、失败、不确定或禁用事实以降低容量；历史完整性依赖可信 Host，并在接口说明中明确边界。

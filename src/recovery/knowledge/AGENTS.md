# 知识库开发规范

继承 [项目规范](../../../AGENTS.md) 与 [恢复规范](../AGENTS.md)。候选、检索、来源、验证及检查点接口约定见 [README](README.md)，覆盖归属见 [集中测试](../../../tests/README.md)。

- 模型与外部来源仅提供候选证据；不从其输入生成可信验收、复用资格、审批或许可，不在本域运行解释器。
- 候选/案例 ID 幂等和脚本版本全局不可变约束使用同一写入与恢复校验；失败、Unknown 或禁用的版本保持永久隔离。
- 可信验收参数只由认证应用显式构造，保持操作/目标/版本/验证者/证据/时间绑定，不增加模型可反序列化或调用的成功写入路径。
- 检索保持精确适用性和可信排序，隔离与复用过滤先于限额；外部批次保持固定来源、有界字段/字节和整体冲突拒绝，查询摘要不包含脚本文本。
- 写盘同步先于内存发布；不弱化文件身份、单写锁、容量拒绝、损坏拒绝、写失败停用和关闭后的只读边界。
- 压缩导出要求可靠持锁的源日志持有者并保留全部权威事实和幂等键；回放从事实推导状态与隔离后核对声明，不以删案例、删版本或调整记录版本号绕过容量。

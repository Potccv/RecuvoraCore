# 故障存储内部规范

继承 [项目规范](../../../AGENTS.md) 与 [恢复规范](../AGENTS.md)。本域接口约定见 [README](README.md)，覆盖归属见 [集中测试](../../../tests/README.md)。

- 检查点与有序信号批次保持同一同步事务；迁移准备为纯计算，同步失败不发布内存或游标。
- 实时提交与回放复用同一迁移检查，内部准备和安装接口只在故障存储域可见。
- 保持异常样本与故障轮次的区别、Unknown 观察不解除及确认只记录关注的语义，不能由本域触发授权或修复。
- 不弱化单写锁、文件对象身份、路径隔离、损坏拒绝、写失败停用或关闭后的只读生命周期。

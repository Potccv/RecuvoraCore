# 持久恢复流程规范

继承[恢复编排规范](../AGENTS.md)，范围见[恢复流程接口约定](README.md)。审批、故障与知识库写入分别遵守[审批规范](../../approval/AGENTS.md)、[故障规范](../../incidents/AGENTS.md)及[知识库规范](../../knowledge/AGENTS.md)。

- 调整审批关联提交时保持完整申请意图与原操作身份；重试不得重建方案或续期，具体恢复约束见[恢复流程](../../../../docs/recovery.md)。
- 重新诊断只限流程允许的复用失败、已确认停止及剩余预算；不得扩大为所有明确失败的自动重试，也不得用重新诊断代替核实未知执行结果（`Unknown`）。
- `Publishing` 保持独立持久阶段；知识库写入重试保留同一操作与结果，不重新执行动作。
- 外部异步调用不持有状态锁；当前故障复查的同步提交回调内不得发起远端调用或重入故障来源。
- 修改独立故障轮次、目标归属、日志格式、迁移或查询摘要时遵守[领域维护](../../../../docs/domain-maintenance.md)，不让维护 API 增加派发资格。
- 公开接口、证据字段与运行文件名称遵守[接口约定](README.md#公开接口与持久记录)，领域数据和持久 JSON 严格校验当前字段。

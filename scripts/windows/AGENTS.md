# Windows 脚本规范

继承[脚本规范](../AGENTS.md)。入口见 [README](README.md)。

- 使用 Rust 标准库和 Windows 平台接口校验输出路径；保持禁止 unsafe，不引入外部脚本运行时依赖。
- 编译时记录的源码位置与输出目录均须完成路径校验；任何目录创建或 Cargo 启动之前先校验全部输出路径，拒绝重解析链接、源码内输出和互相包含的构建与临时目录。
- 顺序等待每个 Cargo 子进程，保留首次失败的非零退出码；参数、路径或启动失败不得报告为检查成功。
- 新增脚本行为同步维护参数、编译步骤和失败约定；相关回归测试集中放在项目测试目录。

# 核心脚本规范

继承 [项目规范](../AGENTS.md)。入口见 [README](README.md)。

- 输出路径须在创建或写入前完成解析与源码隔离、祖先链接检查，不能只依赖 `.gitignore`。
- 脚本按平台放入对应子目录，以独立 Rust 源文件实现，不新增 Cargo 包或产品可执行目标。
- 不修改全局工具链、调用方环境变量或凭据；输出路径和测试并发仅通过子进程环境设置。
- 检查失败返回非零结果；不把未执行的检查报告为通过。
- 清理只限本次创建且记录的资源，不递归清空调用方目录。
- 脚本参数、编译方式、执行顺序和退出行为同步维护到所属平台 README；本目录 README 只维护平台导航，不加入与其职责无关的安装、部署或网络操作。

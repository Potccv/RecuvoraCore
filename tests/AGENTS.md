# 核心测试规范

继承[项目规范](../AGENTS.md)，目标归属见[测试导航](README.md)。

- 领域回归使用内存状态、显式时间和中立证据；不重新引入磁盘存储、异步运行时、外部执行器或应用配置。
- 变更测试同时覆盖纯准备、未确认时原状态不变、错误回执、确认后效果、历史重放与不合法输入。
- 审批关联、当前政策、一次许可、Unknown、可信验收、永久隔离、经验交付顺序与显式恢复均保持行为覆盖。
- 调用方提交回执是测试中的可信断言，不证明真实存储事务。分布式所有权、进程监督、持久介质和跨机执行由集成项目验证。
- 开发脚本测试确需临时文件时使用源码外 RECUVORA_TEST_TEMP，只清理自身创建的资源；测试集中注册于 Cargo 清单或对应独立脚本入口。

# 核心测试规范

继承 [项目规范](../AGENTS.md)。目标登记、模块归属与验证范围见 [README](README.md)，检查环境见 [脚本说明](../scripts/README.md)。

- 测试源码集中在本目录；集成目标显式登记到 Cargo 清单，私有状态测试由所属源码模块通过 `#[path]` 引入。调整注册时同步本目录映射。
- 状态机修改覆盖实时提交和持久恢复的相同不变量，特别是审批关联、一次许可、Unknown、未知执行结果核实、可信验收与修复经验保存边界。
- 使用假 `RepairBackend`、可控时钟和中立证据；故障注入只操作本测试创建的日志，不引入真实脚本、网络、Harness（AI 服务接入）、节点或应用配置。
- 本机子进程锁证据与业务恢复证据分别描述，不能把夹具成功或日志读回写成真实恢复验收。

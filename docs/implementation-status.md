# 实现状态

版本 0.2.0，单 Cargo 库包，公开顶层模块为 `operation` 和 `recovery`。

已实现稳定条件合并、精确经验匹配、完整命中计数、32 KiB 内最多四条整条经验选择，以及从明确结果与总结构造经验。已知与未知故障使用同一请求，始终要求总结与脚本化评估。

库中没有授权、故障台账、任务状态机、提交协议、历史恢复或经验交付队列。无 I/O、锁、系统时钟、调度和外部执行；业务数据不能产生许可。

## 验证范围

使用 Rust 1.98.1 Windows GNU LLVM 工具链，通过现有完整检查入口的格式、严格 Clippy、10 项业务回归及 1 项文档示例。Markdown 链接、锚点和差异空白检查通过。测试覆盖见[测试导航](../tests/README.md)。

本库不提供语义经验检索、候选脚本自动晋升或外部调用。真实执行、持久化和业务恢复不属于本库验收范围。

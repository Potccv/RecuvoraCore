# Core 与 Host 边界入口

Core 维护恢复决策、具有最终效力的状态和稳定业务接口。Host 维护服务启动与组合、外部能力路由和跨进程协议实现与规范；完整角色与接口职责见[架构](architecture.md)。

新增能力按当前职责直接归属：连接地址、节点工作区、传输方式、定时处理、CLI/HTTP、配置加载、能力注册和界面数据转换属于 Host；采集、外部检查、执行与业务验收属于节点/插件。Core 只通过业务接口接收证据，不引入相应应用实现。

现有模块入口见[核心源码](../src/README.md)，可用能力和验证限制见[实现状态](implementation-status.md)。Core API 可用不表示 Host 已接入，独立项目不自动同步。
